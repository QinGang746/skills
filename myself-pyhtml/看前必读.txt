
================================================================================
                        看前必读 — myself-pyhtml
================================================================================

【项目简介】
  一键将彩票开奖 TXT 数据生成交互式 HTML 仪表盘。
  每天只需双击运行，自动检测新数据并更新。

================================================================================

【目录结构】
  myself-pyhtml/
  ├── config.json              接口配置文件（url/headers/参数）
  ├── 01-data/
  │   ├── 01-template/         波色号码对照表（固定，勿删）
  │   └── 02-txt-source/       开奖数据源（每年一个 txt）
  ├── 02-script/              所有脚本 + 配置
  │   ├── config.json           接口配置（url/headers）
  │   ├── requirements.txt      依赖清单
  │   ├── env_install.bat       环境一键安装（纯bat，首次用）
  │   ├── env_setup.py          环境检测 + 依赖补全
  │   ├── fetch_data.py         从接口拉取最新数据
  │   └── generate.py           合并数据 + 生成 Excel + 生成 HTML
  ├── output/                  产物目录
  ├── run.bat                  双击启动（拉取 + 生成）
  └── 看前必读.txt             本文件

================================================================================

【接口配置】
  接口变更时只需编辑 02-script/config.json（无需改代码）：
  {
      "api": {
          "url":     "接口地址",
          "headers":  { 请求头，含 Referer/User-Agent },
          "body":     { 请求参数，年份 y 由代码自动填充 },
          "timeout":  超时秒数（默认 300）
      }
  }

================================================================================

【环境要求】
  首次使用请按顺序操作：

  第一步：安装 Python
    下载 Python 3.7+：https://www.python.org/downloads/
    安装时务必勾选 "Add Python to PATH"

  第二步：一键安装环境
    双击 env_install.bat（自动检测 Python + 安装依赖）

  环境安装完成后，后续每天只需双击 run.bat 即可。

【脚本命名规范】
  env_ 前缀 = 环境脚本（首次配置用）
  无前缀   = 业务脚本（日常使用）
  ├── env_install.bat   环境一键安装（纯 bat，不用 Python）
  ├── env_setup.py      环境检测 + 依赖补全
  ├── fetch_data.py     拉取接口数据
  └── generate.py       生成 Excel + HTML

================================================================================

【使用方法】

  方式一（推荐）：双击 run.bat
    → 自动执行三步：拉取接口数据 -> 生成 Excel -> 生成 HTML
    → 完成后窗口显示产物路径，按回车关闭。

  方式二：分步执行（在 myself-pyhtml 目录下）
    python 02-script\fetch_data.py   # 仅从接口拉取 2026 最新数据
    python 02-script\generate.py      # 合并数据 + 生成 Excel + 生成 HTML

  执行逻辑：
    首次运行：合并所有 txt -> 生成 Excel -> 生成 HTML
    后续运行：fetch_data 从接口拉取最新数据 -> 检测是否有新增 -> 重新生成

================================================================================

【数据来源】
  2026 年数据通过接口自动拉取（fetch_data.py）：
    接口: POST https://kj.9bkj.com:1888/kj
    参数: {"g":"am","y":2026}
  拉取后自动按 id 去重合并到 01-data/02-txt-source/临时测试-2026.txt

  2020~2025 年历史数据已在 txt-source 中，通常不需改动。
  如需修正历史数据，直接编辑对应 txt 即可，下次运行自动合并。

【产物说明】
  运行后在 output/ 目录生成：

  开奖记录-全年份合并.xlsx
    → 7 年开奖数据合并的 Excel 表格（29 列，含农历、波色、列拆分）

  开奖记录-全年份合并-report-YYYYMMDD-HHMMSS.html
    → 浏览器直接打开的交互式仪表盘，含 8 个 Tab：
      首页概览 / 频率统计 / 遗漏·冷热 / 分年统计 / 走势图 /
      走势图(分年) / 历史记录 / 连开·重号

【常见问题】

  Q: 双击 run.bat 没反应？
  A: 打开 cmd 进入目录执行 python generate.py，查看报错信息。

  Q: 提示 No module named 'openpyxl' / 'requests'？
  A: 执行 pip install -r requirements.txt 安装全部依赖。

  Q: 接口拉取失败（[失败] 提示）？
  A: 网络原因接口可能暂时不可达，脚本会自动跳过拉取，
     保留现有数据继续生成。可稍后重试或手动更新 txt 文件。

  Q: 历史年份数据有误怎么修正？
  A: 直接编辑 01-data/02-txt-source/ 下对应年份的 txt，
     然后删除 output/ 下的 xlsx 文件，重新运行即可全量生成。

  Q: 浏览器打开 HTML 是空白？
  A: 确保用 Chrome/Edge 等现代浏览器打开，IE 不支持。
